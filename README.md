# Assignment 4 - Backend Project

Starter backend scaffold for the Apollo-Level2-Web-Dev B7A4 assignment.

## Stack

- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL
- JWT authentication
- Stripe payment integration

## What is included

- `src/` for the application source code
- `prisma/schema.prisma` for the database schema
- `src/middleware/errorHandler.ts` for structured errors
- `src/validation/` for request validation
- `src/routes/` for endpoint grouping
- `src/controllers/` for request handlers

## Quick start

1. Install dependencies.
2. Copy `.env.example` to `.env`.
3. Run Prisma migrate and seed.
4. Start the dev server.

## Assignment notes

This repo is scaffolded to support the mandatory requirements from the brief:

- structured error responses
- server-side validation
- admin credentials setup
- Stripe or SSLCommerz payment flow
- Postman or Swagger API documentation
- meaningful commit history
